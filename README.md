# 打卡助手（测试版小程序）

微信小程序打卡功能：**管理员地图选点 + 员工按距离打卡**。

## 架构

- 前端：微信小程序（本目录根目录）
- 后端：Rust / axum / SQLite（`server/` 目录），部署在 `cjq.tencent`（公网 `43.138.230.64:3000`）
- 前端 API 地址配置在 `utils/api.js` 的 `BASE_URL`

### 开发调试注意

后端目前是 HTTP + IP 地址，真机预览需要在微信公众平台配置 HTTPS 合法域名；
在开发者工具里需要勾选：**详情 → 本地设置 → 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**。

## 功能

- 角色登录：管理员 / 员工，默认密码均为 `123456`
- 管理员：地图选点（`wx.chooseLocation`）、设置允许半径、查看/清空打卡记录
- 员工：实时时钟、获取当前定位、按距离判断是否在范围内、每日打卡、查看记录

## 运行

1. 打开「微信开发者工具」 → 导入项目 → 选择本目录。
2. AppID 可选择「测试号」或直接游客模式（`project.config.json` 中默认 `touristappid`，可改成你自己的 AppID）。
3. 编译运行即可。

## 测试定位

在开发者工具模拟器中：

- 菜单 **设置 → 通用设置 → 地理位置** 可设置模拟经纬度。
- 管理员选点时，地图搜索框可直接搜索地点名称，选中后保存。
- 员工端点「刷新定位」重新获取位置，观察距离和范围内状态变化。
- 把模拟坐标设到打卡点附近（< 半径）为「范围内」，设远一点为「范围外」。
